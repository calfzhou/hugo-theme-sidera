Sidera is an independent Hugo theme for blogs, notebooks and documentation. Native
sections organize your content; optional presets supply convenient defaults without
locking pages into a special format. Local search and references connect the result.

## Choose your next step

- [Get started](getting-started/_index.md): install the theme and publish a first page.
- [Organize content](organize/_index.md): choose sections, bundles, presets and taxonomies.
- [Customize your site](customize/_index.md): identity, menus, widgets, footers and icons.
- [Write content](authoring/_index.md): Markdown, images, math, code and components.
- [Reader features](reader/_index.md): search, references, comments and configured text.
- [Reference and help](publishing/_index.md): parameters, shortcode arguments and troubleshooting.

This English manual is AI-generated; each page carries the theme's visible disclosure.
Theme controls are available in English and Simplified Chinese. Content is not
translated automatically. [Embed this manual](getting-started/embed.md) only when you
want it on your site; activating Sidera alone does not publish it.

Sidera takes layout and interaction inspiration from **Hexo Stellar 1.44.0** by
**xaoxuu**. It is not an official port and does not use Stellar's configuration API.
See [credits and licenses](publishing/credits.md).
